Student Performance Analysis

About the Project

This project analyzes student performance using Python, Pandas, and Matplotlib. It helps understand students' marks, average scores, and attendance.

Objectives

- Calculate the average marks of each student.
- Identify the highest and lowest scoring students.
- Calculate subject-wise average marks.
- Visualize student performance using graphs.
- Explore the relationship between attendance and average marks.

Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

Visualizations

- Subject-wise average marks (bar chart)
- Student-wise average marks (horizontal bar chart)
- Attendance vs average marks (scatter plot)

Key Insights

- Identified the highest and lowest scoring students.
- Compared average marks across Python, SQL, and Maths.
- Visualized attendance against average marks.

How to Run

1. Clone or download this repository.
2. Install the required libraries:
   "pip install pandas matplotlib"
3. Open "analysis.ipynb" in Jupyter Notebook.
4. Run the notebook cells in order.
